Image treatment

Small, sharp and secondary to the quote.

  • Display size96px desktop, 72px mobile
  • Source minimum192px square for a 2x display
  • FallbackUse initials when the source is too small
  • Crop1:1 with object-fit: cover

Site-wide image rules

Large enough to look sharp. Never larger than the content needs.

01No upscaling

An image is never displayed above its useful native resolution.

02Responsive sources

Use 640, 960, 1440 and 1920px variants only where the original supports them.

03Correct fit

Use contain for artwork and packshots, cover for editorial photography.

04Measured display

Full-width visuals cap at 1440px. Portraits cap at 720px. Headshots cap at 96px.

05Performance

Declare dimensions, use srcset and sizes, and lazy-load below-the-fold images.
