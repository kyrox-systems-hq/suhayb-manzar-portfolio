Before you configure

Questions that should not interrupt the buying journey.

Do I need exact measurements to begin?−

You can begin with the opening you are planning and use the guidance built around each configurator. Final technical details can be confirmed before manufacture.

Which door system is right for my opening?+

Bifold doors prioritise a wide open aperture, sliding doors prioritise large glazed panels, while French and single doors suit more conventional access points.

Can I get help while configuring?+

Yes. Phone and WhatsApp support remain visible throughout the journey so customers can resolve a technical question without abandoning the page.
